# Resource icon credits

Original artwork is bundled unchanged, apart from a warm ivory colour for the two monochrome collections. SVG originals and 128px PNG exports are included. All icons load locally, without network requests.

- Game Icons — https://game-icons.net/ — CC BY 3.0. Icons by Delapouite (wood-pile, clay-brick, sheep, rolled-cloth, two-coins), Faithtoken (ore), and Lorc (wheat, scroll-unfurled). Attribution and individual source mapping: sources.json. https://creativecommons.org/licenses/by/3.0/
- Pictogrammers Material Design Icons — https://pictogrammers.com/library/mdi/ — Apache 2.0.
- Microsoft Fluent Emoji Flat — https://github.com/microsoft/fluentui-emoji — MIT.
- Google Noto Emoji — https://github.com/googlefonts/noto-emoji — Apache 2.0.
- Twemoji — https://github.com/jdecked/twemoji — graphics CC BY 4.0. https://creativecommons.org/licenses/by/4.0/

Data distributed by Iconify: https://github.com/iconify/icon-sets.
The emoji collections use sheaf-of-rice for wheat, yarn for cloth, and ewe for wool. Pictogrammers uses barley, a shirt for cloth, a stone for ore, and stacked circles for coins.
