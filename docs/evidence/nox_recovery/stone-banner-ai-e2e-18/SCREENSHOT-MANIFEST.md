## Boundary and outstanding coverage

- Waydroid screenshot 007 is an **old APK**, not proof of the newly built release. Device was in use (Android user 11); no UI gestures, installs, rotation or semantics/TalkBack on Waydroid.
- Attempted GTK dark and DPI scaling produced **byte-for-byte identical** PNGs to normal light 390×844 screens. Therefore only light/normal text is visually validated; 1.6× light / 2.0× dark responsive layouts were validated with Flutter widget tests, not actual screenshots.
- Linux 390×844 is a phone-sized **desktop** viewport, not mobile touch or safe-area validation. Keyboard Tab/Escape, hover and responsive sizing were exercised; focus styling remains subtle.
- Complex match secondary actions were restructured and separately widget-tested; no new match/gameplay UI actions were performed in this slice. Full device board flows, all dialogs, actual mobile large-text themes and screenreader semantics still need E2E follow-up.
