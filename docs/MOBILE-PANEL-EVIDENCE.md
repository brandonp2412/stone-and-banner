# Mobile action panel — 16 November 2026

The phone action rail now uses up to 320 logical pixels (48% on small screens), with an expand/narrow control for up to 460 pixels. Build actions are full-width rows with visible costs. Selecting a build action narrows the panel again for map placement. Desktop keeps its existing 320–420 pixel sizing.

Each tab has its own scroll controller, a draggable visible scrollbar, and a saved scroll position. Expandable defence and development sections have separate storage keys so their boolean expansion state cannot collide with the list's numeric offset. Tabs, turn action, map and inventory stay outside the scrolling content. Standings allow more horizontal room at larger text sizes.
